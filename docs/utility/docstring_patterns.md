# Docstring patterns for Alpha9

## Module-Level
```
"""
[Title].

[Paragraph Description]

[Requirements]

[Usages]
"""
```

## Class-Level
```
"""
[Paragraph Description]

Attributes:
    [attribute: description]
"""
```

## Function-Level
```
"""
[Paragraph Description]

Args:
    [argument: description]
    
Returns:
    [return_variable: description]
    
Raises:
    [error_name: description]
"""
```
